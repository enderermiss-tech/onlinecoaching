# Anlık Koç — Gerçek Zamanlı Temsilci Koçluğu

Tahsilat, müşteri hizmetleri, satış sonrası hizmetler ve satış ekipleri için görüşme sırasında hızlı iletişim önerileri sunan web MVP'si.

## MVP kapsamı
- 4 soruluk temsilci akışı
- Yerel demo öneri motoru
- 4 ücretsiz deneme hakkı
- Bireysel paket: 250 TL + KDV / kişi / ay
- Kurumsal paket alanı
- Mobil uyumlu landing page

## Üretim yol haritası
1. Sunucu tarafında gerçek LLM entegrasyonu
2. Kullanıcı hesabı ve kota sistemi
3. Ödeme altyapısı
4. Yönetici paneli ve ekip raporları
5. Kuruma özel iletişim rehberi / bilgi tabanı
6. İkinci aşamada canlı görüşme transkripsiyonu ve gerçek zamanlı öneriler

## Güvenlik notu
API anahtarları istemci tarafına eklenmemelidir. Gerçek AI bağlantısı sunucu tarafında yapılmalıdır.
